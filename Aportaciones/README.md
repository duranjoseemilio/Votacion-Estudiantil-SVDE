# Aportaciones originales del equipo

Estas carpetas conservan los archivos que estaban en la rama principal antes de organizar la entrega final:

- `Interfaz`: contenido original de la carpeta SDVE, incluida su conexion inicial con el modulo de datos.
- `BaseDatos`: contenido original de BaseDatos, incluidas sus pruebas.
- `Conteo_Resultados`: contenido original de Proyecto.

Se conservan sin modificar su codigo como referencia del desarrollo por modulos. Para ejecutar el sistema completo se utiliza la carpeta SDVE situada en la raiz del repositorio, no estas versiones parciales.

Aquí conservamos las aportaciones originales de interfaz, base de datos y conteo de resultados.
